# اختبارات القبول

AT-001: مستخدم مخول ينشئ طلبًا صحيحًا؛ ينشأ سجل واحد بحالة NEW ورقم فريد.
AT-002: مستخدم غير مخول يطلب عقارًا أو طلبًا؛ يمنع دون تسريب بيانات.
AT-003: مستخدم مؤسسة A لا يقرأ أو يعدل بيانات مؤسسة B.
AT-004: مقدم خدمة غير مؤهل أو خارج التغطية يستبعد قبل الترتيب.
AT-005: يمنع بدء عمل غير طارئ قبل موافقة سعر صالحة.
AT-006: تعديل عرض معتمد ينشئ إصدارًا جديدًا ولا يغير النسخة المعتمدة.
AT-007: يمنع الانتقال غير المسموح مثل NEW→COMPLETED.
AT-008: رفع تقرير الإنجاز ينقل الطلب إلى AWAITING_ACCEPTANCE لا COMPLETED.
AT-009: قبول العميل يغلق وفق السياسة؛ الاعتراض ينشئ مسار إعادة عمل/نزاع.
AT-010: عرض مورد منتهي الصلاحية لا يظهر كتوافر مؤكد.
AT-011: ملف غير مسموح أو أكبر من الحد يرفض ولا يصبح متاحًا.
AT-012: لا يسجل الدفع مدفوعًا بناء على قيمة من المتصفح وحدها.
AT-013: كل تغيير حالة أو سعر أو صلاحية ينشئ سجل تدقيق.
AT-014: إعادة طلب الإنشاء بنفس Idempotency-Key لا تنشئ تكرارًا.
AT-015: العربية RTL تعمل عند عرض 360px دون قص جوهري أو تمرير أفقي غير مقصود.
AT-016: تعطل الخرائط/الرسائل لا يفقد الطلب؛ تسجل إعادة المحاولة.
AT-017: مسؤول المؤسسة لا يمنح دور مسؤول المنصة العالمي.
AT-018: العمل الإضافي يتطلب موافقة قبل التنفيذ غير الطارئ.

لا تعتمد المرحلة إذا فشلت اختبارات ذات صلة أو بقيت ثغرات حرجة/عالية غير معالجة. وثّق الاختبارات غير المنفذة.
