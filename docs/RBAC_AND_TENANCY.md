# الأدوار والصلاحيات وعزل البيانات

## الأدوار
CUSTOMER_OWNER، AUTHORIZED_TENANT، PROPERTY_STAFF، CORPORATE_MANAGER، PROVIDER_ADMIN، TECHNICIAN، SUPPLIER_USER، OPERATIONS_AGENT، QUALITY_SAFETY_REVIEWER، FINANCE_AGENT، ORG_ADMIN، PLATFORM_ADMIN.

## القاعدة
كل طلب API يتحقق من الهوية، والفعل، ونطاق السجل. لا يكفي تسجيل الدخول.

## الصلاحيات النموذجية
- المالك: عقاراته وطلباتها واعتمادات ضمن تفويضه.
- المستأجر: طلبات الوحدات المخوّل بها، دون ملكية أو صلاحيات مالية غير ممنوحة.
- مدير الشركة: عقارات وطلبات وتقارير ضمن مؤسسته.
- الفني: المهام المسندة إليه فقط.
- المورد: منتجاته وعروضه وطلبات التوريد المرتبطة به فقط.
- العمليات: الفرز والإسناد والمتابعة وفق نطاق الصلاحية.
- الجودة: سجلات الفحص والحوادث والشكاوى اللازمة للمراجعة.
- المالية: الفواتير والتسويات ضمن التفويض.
- مسؤول المؤسسة: أعضاء مؤسسته، دون صلاحيات عالمية.
- مسؤول المنصة: إعدادات عامة؛ الوصول الاستثنائي إلى بيانات العملاء مسبب ومسجل.

## قواعد إلزامية
1. منع IDOR والتحقق من كل سجل على الخادم.
2. تقييد الاستعلامات بحسب المؤسسة والعضوية وتفويض العقار.
3. فصل الملاحظات الداخلية عن معلومات العميل.
4. تسجيل منح الصلاحيات والتصدير والوصول الاستثنائي.
5. إبطال الجلسات عند تعطيل الحساب أو تغيير الدور.
6. اختبارات سلبية لكل دور.
7. أقل صلاحية ممكنة.
