# مواصفات الشاشات

## قواعد عامة
RTL افتراضيًا، تصميم متجاوب، حالات تحميل/فراغ/خطأ/نجاح، تحقق خادمي، عرض الأسعار بالريال مع تفاصيل الرسوم والضريبة عند انطباقها.

## S01 الدخول
مصادقة عبر مزود هوية موثوق، رسائل لا تكشف وجود الحساب، حماية من المحاولات المتكررة.

## S02 اختيار المؤسسة والدور
عرض العضويات المسموح بها فقط.

## S03 لوحة العميل
الطلبات المفتوحة، العقارات المصرح بها، المواعيد، الفواتير والتنبيهات.

## S04 العقارات والوحدات
إنشاء وتعديل وأرشفة العقار، إدارة الوحدات وجهات الاتصال وتعليمات الوصول ذات الصلاحية المحدودة. لا تحذف السجلات التاريخية نهائيًا.

## S05 إنشاء طلب
العقار/الوحدة، الفئة، الوصف، الصور، الوقت المفضل، الاستعجال المقترح. تحقق من تفويض المستخدم والملفات. أنشئ حالة NEW فقط ولا توحِ بأن الإسناد تم.

## S06 تفاصيل الطلب
الحالة، سجل الأحداث، الموعد، التشخيص، عروض السعر، المواد، الملفات، الفاتورة، الضمان والشكوى. اخفِ الملاحظات الداخلية عن غير المخولين.

## S07 مركز العمليات
فرز حسب الحالة والخطورة والمنطقة والتأخير؛ التعيين اليدوي يتطلب سببًا مسجلًا.

## S08 دليل مقدمي الخدمة
التخصصات، مناطق التغطية، التوفر، التقييم، الوثائق وحالة التحقق.

## S09 بوابة الفني
المهام المسندة فقط، قبول/رفض، تشخيص، عرض سعر، تقدم العمل، أدلة وصور الإنجاز.

## S10 السعر والموافقة
أجرة، مواد، رسوم زيارة، خصم، ضريبة عند انطباقها، الإجمالي، الافتراضات والاستثناءات والضمان. العرض المعتمد immutable؛ أي تعديل إصدار جديد.

## S11 سوق الموردين
كتالوج ومواصفات ووحدة قياس وسعر ووقت تحديث وتوفر ورسوم توصيل وموعد تقديري. لا تعرض توفرًا مؤكدًا دون تحقق حديث.

## S12 طلب التوريد
بنود وكميات ومورد وعقار وطلب مرتبط وعنوان تسليم وحالة. البديل يحتاج موافقة إذا غيّر المواصفات أو السعر.

## S13 التنفيذ والسلامة
الوصول، التشخيص، تقييم المخاطر، المواد، صور قبل/بعد، قائمة فحص، تقرير الإنجاز.

## S14 الاستلام والضمان والشكوى
قبول أو إعادة عمل أو نزاع، ضمان، شكوى ومرفقات. لا تغلق تلقائيًا لمجرد عدم الرد إلا وفق سياسة معلنة ومعتمدة.

## S15 الفواتير والدفع
حالة الدفع من مزود موثوق؛ لا تعتمد قيمة من المتصفح. لا تخزن بيانات البطاقة.

## S16 التقارير
الطلبات، الاستجابة، الإنجاز، التكاليف، إعادة الإصلاح، رضا العملاء وأداء الموردين، مع عزل البيانات وتعريف المؤشرات.

## S17 المستخدمون والصلاحيات
دعوة، دور، نطاق عقارات، تعطيل، سجل تدقيق. مسؤول المؤسسة لا يمنح دور مسؤول منصة عالمي.

## S18 الجودة والسلامة
حوادث، قوائم فحص، إجراءات تصحيحية، تدقيق وقيود وصول.
