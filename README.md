## قرارات تأسيسية
1. تطبيق ويب متجاوب PWA أولًا.
2. بنية Modular Monolith في البداية.
3. PostgreSQL؛ ويمكن إضافة PostGIS عند تنفيذ البحث المكاني.
4. بيانات العرض التجريبية لا تمثل بيانات حقيقية.
5. لا يُعلن نجاح دفع أو توفر مخزون أو موقع حي دون تكامل موثوق.
6. صلاحيات الخادم هي المرجع؛ إخفاء الأزرار ليس حماية.
7. الأعمال عالية الخطورة والإنشائية تحتاج مختصًا مؤهلًا.
8. راجع المتطلبات القانونية والضريبية والتنظيمية السعودية قبل الإطلاق.

ابدأ بقراءة prompts/AI_BUILD_PLAN.md ونفّذ مرحلة واحدة فقط في كل مرة.
هذه مواصفات تأسيسية تحتاج مراجعة تقنية وقانونية قبل الإنتاج.
